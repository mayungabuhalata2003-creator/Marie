# Kwa Maarie

Ukurasa mmoja wa HTML (login, karibu, barua, ombi). Hauhitaji build wala package.

## GitHub
1. Tengeneza repo mpya (mfano `maarie-site`) kwenye github.com.
2. Weka `index.html` na `README.md` ndani ya repo (Add file > Upload files), kisha Commit.

## Render
1. render.com > New > Static Site > chagua repo.
2. Build Command: acha tupu
3. Publish Directory: `.`
4. Create Static Site. Ndani ya dakika chache utapata kiungo cha `onrender.com`.
